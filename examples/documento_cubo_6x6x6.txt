# Documento Técnico del Cubo 6×6×6 - QubitCoin

## Descripción Matemática

El cubo 6×6×6 es una extensión aún más compleja de la familia de cubos de Rubik. Este cubo proporciona un nivel extremo de complejidad matemática para aplicaciones que requieren seguridad máxima.

### Grupo de Permutaciones

El estado del cubo 6×6×6 puede representarse como un elemento del grupo de permutaciones:

G = S96 × S96 × S8 ⋊ (Z2^96 × Z3^8)

Donde:
- S96: permutaciones de las 96 piezas centrales (24 centros por cara × 6 caras - 4 centros por vértice × 8 vértices / 4)
- S96: permutaciones de las 96 piezas de borde
- S8: permutaciones de las 8 esquinas
- Z2^96: orientaciones de las piezas de borde
- Z3^8: orientaciones de las esquinas

### Espacio de Estados

- Número total de estados posibles: ≈ 1.6 × 10^116
- Número de estados alcanzables mediante giros legales: ≈ 1.6 × 10^116
- Este número excede significativamente el número de átomos en el universo observable (≈ 10^80)

- **Tiempo de Verificación**: < 1 ms
- **Nivel de Seguridad**: Superior a NIST PQC Security Level 5

## Código Rust para el Cubo 6×6×6

```rust
use std::fmt;

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Center {
    pub piece: u8,      // Identificador de la pieza central (0-95)
    pub face: u8,       // Cara a la que pertenece (0-5)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Edge {
    pub piece: u8,      // Identificador de la pieza de borde (0-95)
    pub orientation: u8, // Orientación (0, 1)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Corner {
    pub piece: u8,      // Identificador de la esquina (0-7)
    pub orientation: u8, // Orientación (0, 1, 2)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Cube6x6x6 {
    centers: [Center; 96],  // 24 centros por cara × 6 caras - 4 centros por vértice × 8 vértices / 4 = 96 centros
    edges: [Edge; 96],      // 16 aristas por cara × 6 caras - 4 aristas por vértice × 8 vértices / 2 = 96 aristas
    corners: [Corner; 8],   // 8 esquinas
}

impl Cube6x6x6 {
    pub fn new() -> Self {
        // Estado resuelto
        let mut centers = [Center { piece: 0, face: 0 }; 96];
        let mut edges = [Edge { piece: 0, orientation: 0 }; 96];
        let corners = [
            Corner { piece: 0, orientation: 0 }, // UFR
            Corner { piece: 1, orientation: 0 }, // UFL
            Corner { piece: 2, orientation: 0 }, // ULB
            Corner { piece: 3, orientation: 0 }, // UBR
            Corner { piece: 4, orientation: 0 }, // DFR
            Corner { piece: 5, orientation: 0 }, // DFL
            Corner { piece: 6, orientation: 0 }, // DLB
            Corner { piece: 7, orientation: 0 }, // DBR
        ];
        
        // Inicializar centros
        for i in 0..96 {
            centers[i] = Center { piece: i as u8, face: (i / 16) as u8 };
        }
        
        // Inicializar aristas
        for i in 0..96 {
            edges[i] = Edge { piece: i as u8, orientation: 0 };
        }
        
        Cube6x6x6 {
            centers,
            edges,
            corners,
        }
    }

    // Movimiento U (gira la cara superior 90 grados en sentido horario)
    pub fn move_u(&mut self) {
        // Permutar centros U (fila superior)
        let temp_centers_row1 = [
            self.centers[0], self.centers[1], self.centers[2], 
            self.centers[3], self.centers[4], self.centers[5]
        ];
        self.centers[0] = self.centers[5];  // UR -> UF
        self.centers[1] = temp_centers_row1[0];  // UF -> UL
        self.centers[2] = temp_centers_row1[1];  // UL -> UB
        self.centers[3] = temp_centers_row1[2];  // UB -> UBL
        self.centers[4] = temp_centers_row1[3];  // UBL -> UBR
        self.centers[5] = temp_centers_row1[4];  // UBR -> UR
        
        // Permutar aristas U
        let temp_edges = [self.edges[0], self.edges[1], self.edges[2], self.edges[3]];
        self.edges[0] = self.edges[3];  // UR -> UF
        self.edges[1] = temp_edges[0];  // UF -> UL
        self.edges[2] = temp_edges[1];  // UL -> UB
        self.edges[3] = temp_edges[2];  // UB -> UR
        
        // Permutar esquinas U
        let temp_corners = [self.corners[0], self.corners[1], self.corners[2], self.corners[3]];
        self.corners[0] = self.corners[3];  // UFR -> UBR
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[2] = temp_corners[1];  // ULB -> UFL
        self.corners[3] = temp_corners[2];  // UBR -> ULB
    }

    // Movimiento R (gira la cara derecha 90 grados en sentido horario)
    pub fn move_r(&mut self) {
        // Permutar centros R
        let temp_centers_row1 = [
            self.centers[16], self.centers[17], self.centers[18], 
            self.centers[19], self.centers[20], self.centers[21]
        ];
        self.centers[16] = self.centers[21];  // RF -> RB
        self.centers[17] = temp_centers_row1[0];  // RU -> RF
        self.centers[18] = temp_centers_row1[1];  // RM -> RU
        self.centers[19] = temp_centers_row1[2];  // RM -> RM
        self.centers[20] = temp_centers_row1[3];  // RD -> RM
        self.centers[21] = temp_centers_row1[4];  // RB -> RD
        
        // Permutar aristas R
        let temp_edges = [self.edges[16], self.edges[17], self.edges[18], self.edges[19]];
        self.edges[16] = self.edges[19];  // RF -> RB
        self.edges[17] = temp_edges[0];   // RU -> RF
        self.edges[18] = temp_edges[1];   // RD -> RU
        self.edges[19] = temp_edges[2];   // RB -> RD
        
        // Permutar esquinas R
        let temp_corners = [self.corners[0], self.corners[4], self.corners[7], self.corners[3]];
        self.corners[0] = self.corners[4];  // UFR -> DFR
        self.corners[4] = self.corners[7];  // DFR -> DBR
        self.corners[7] = self.corners[3];  // DBR -> UBR
        self.corners[3] = temp_corners[0];  // UBR -> UFR
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
        self.corners[7].orientation = (self.corners[7].orientation + 2) % 3;
        self.corners[3].orientation = (self.corners[3].orientation + 1) % 3;
    }

    // Movimiento F (gira la cara frontal 90 grados en sentido horario)
    pub fn move_f(&mut self) {
        // Permutar centros F
        let temp_centers_row1 = [
            self.centers[32], self.centers[33], self.centers[34], 
            self.centers[35], self.centers[36], self.centers[37]
        ];
        self.centers[32] = self.centers[37];  // FR -> FD
        self.centers[33] = temp_centers_row1[0];  // FU -> FR
        self.centers[34] = temp_centers_row1[1];  // FM -> FU
        self.centers[35] = temp_centers_row1[2];  // FM -> FM
        self.centers[36] = temp_centers_row1[3];  // FM -> FD
        self.centers[37] = temp_centers_row1[4];  // FD -> FL
        
        // Permutar aristas F
        let temp_edges = [self.edges[32], self.edges[33], self.edges[34], self.edges[35]];
        self.edges[32] = self.edges[35];  // FR -> FD
        self.edges[33] = temp_edges[0];   // FU -> FR
        self.edges[34] = temp_edges[1];   // FD -> FL
        self.edges[35] = temp_edges[2];   // FL -> FU
        
        // Permutar esquinas F
        let temp_corners = [self.corners[0], self.corners[1], self.corners[5], self.corners[4]];
        self.corners[0] = self.corners[5];  // UFR -> DFL
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[5] = temp_corners[2];  // DFL -> DFR
        self.corners[4] = temp_corners[1];  // DFR -> UFL
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 1) % 3;
        self.corners[5].orientation = (self.corners[5].orientation + 2) % 3;
        self.corners[1].orientation = (self.corners[1].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
    }

    // Verifica si el cubo está resuelto
    pub fn is_solved(&self) -> bool {
        // Verificar centros
        for i in 0..96 {
            if self.centers[i].piece != i as u8 {
                return false;
            }
        }
        
        // Verificar aristas
        for i in 0..96 {
            if self.edges[i].piece != i as u8 || self.edges[i].orientation != 0 {
                return false;
            }
        }
        
        // Verificar esquinas
        for i in 0..8 {
            if self.corners[i].piece != i as u8 || self.corners[i].orientation != 0 {
                return false;
            }
        }
        
        true
    }

    // Calcula un hash del estado actual del cubo
    pub fn get_state_hash(&self) -> u64 {
        use std::collections::hash_map::DefaultHasher;
        use std::hash::{Hash, Hasher};
        
        let mut hasher = DefaultHasher::new();
        self.hash(&mut hasher);
        hasher.finish()
    }

    // Aplica una secuencia de movimientos
    pub fn apply_sequence(&mut self, sequence: &str) {
        for move_char in sequence.chars() {
            match move_char {
                'U' => self.move_u(),
                'R' => self.move_r(),
                'F' => self.move_f(),
                'D' => {
                    // Doble movimiento U: U U
                    self.move_u();
                    self.move_u();
                }
                'L' => {
                    // Doble movimiento R: R R
                    self.move_r();
                    self.move_r();
                }
                'B' => {
                    // Doble movimiento F: F F
                    self.move_f();
                    self.move_f();
                }
                ' ' | '\n' | '\t' => continue, // Ignorar espacios
                _ => {} // Otros caracteres se ignoran
            }
        }
    }
}

impl fmt::Display for Cube6x6x6 {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        writeln!(f, "Cube 6x6x6 State:")?;
        writeln!(f, "Centers (first 10):")?;
        for i in 0..std::cmp::min(10, self.centers.len()) {
            writeln!(f, "  Center {}: piece={}, face={}", i, self.centers[i].piece, self.centers[i].face)?;
        }
        writeln!(f, "Edges (first 10):")?;
        for i in 0..std::cmp::min(10, self.edges.len()) {
            writeln!(f, "  Edge {}: piece={}, orientation={}", i, self.edges[i].piece, self.edges[i].orientation)?;
        }
        writeln!(f, "Corners:")?;
        for (i, corner) in self.corners.iter().enumerate() {
            writeln!(f, "  Corner {}: piece={}, orientation={}", i, corner.piece, corner.orientation)?;
        }
        Ok(())
    }
}

impl std::hash::Hash for Cube6x6x6 {
    fn hash<H: std::hash::Hasher>(&self, state: &mut H) {
        self.centers.hash(state);
        self.edges.hash(state);
        self.corners.hash(state);
    }
}

    }

    #[test]

        let mut cube = Cube6x6x6::new();

        // Después de U, las esquinas U deben estar permutadas

        assert_eq!(cube.corners[1].piece, 0); // Antes era 1 (UFL -> UFR)
        assert_eq!(cube.corners[2].piece, 1); // Antes era 2 (ULB -> UFL)
        assert_eq!(cube.corners[3].piece, 2); // Antes era 3 (UBR -> ULB)
    }
}
```

## Aplicaciones en QubitCoin

### Uso en RubikPoW

El cubo 6×6×6 puede utilizarse para:

- Niveles de seguridad extremadamente altos
- Aplicaciones que requieren máxima resistencia cuántica
- Validación de transacciones de alto valor

### Seguridad

- Espacio de estados: ≈ 1.6 × 10^116
- Mayor seguridad que el cubo 4×4×4
