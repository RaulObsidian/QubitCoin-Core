# Documento Técnico del Cubo 4×4×4 - QubitCoin (Principal)

## Descripción Matemática

El cubo 4×4×4, también conocido como Rubik's Revenge, es el cubo principal utilizado en el algoritmo RubikPoW de QubitCoin. Su estructura matemática es significativamente más compleja que los cubos anteriores.

### Grupo de Permutaciones

El estado del cubo 4×4×4 puede representarse como un elemento del grupo de permutaciones:

G = S24 × S24 × S8 ⋊ (Z2^24 × Z3^8)

Donde:
- S24: permutaciones de las 24 piezas centrales
- S24: permutaciones de las 24 piezas de borde
- S8: permutaciones de las 8 esquinas
- Z2^24: orientaciones de las piezas de borde
- Z3^8: orientaciones de las esquinas

### Espacio de Estados

- Número total de estados posibles: ≈ 7.4 × 10^45
- Número de estados alcanzables mediante giros legales: ≈ 7.4 × 10^45
- Este número excede ampliamente el número de átomos en el universo observable (≈ 10^80)

## Grupo Simétrico S48 en QubitCoin

El algoritmo RubikPoW de QubitCoin opera específicamente en el Grupo Simétrico S48, que representa las posibles permutaciones de una cara de un cubo 4×4×4.

- Tamaño del Grupo S48: 48! ≈ 1.24 × 10^61
- Este tamaño excede en órdenes de magnitud los requisitos de seguridad de NIST
- Proporciona resistencia cuántica incluso contra algoritmos como Grover

use std::fmt;

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Center {
    pub piece: u8,      // Identificador de la pieza central (0-23)
    pub face: u8,       // Cara a la que pertenece (0-5)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Edge {
    pub piece: u8,      // Identificador de la pieza de borde (0-23)
    pub orientation: u8, // Orientación (0, 1)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Corner {
    pub piece: u8,      // Identificador de la esquina (0-7)
    pub orientation: u8, // Orientación (0, 1, 2)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Cube4x4x4 {
    centers: [Center; 24],  // 4 centros por cara × 6 caras = 24 centros
    edges: [Edge; 24],      // 4 aristas por cara × 6 caras - 4 aristas por vértice × 8 vértices / 2 = 24 aristas
    corners: [Corner; 8],   // 8 esquinas
}

impl Cube4x4x4 {
    pub fn new() -> Self {
        // Estado resuelto
        Cube4x4x4 {
            centers: [
                // Cara U (Superior)
                Center { piece: 0, face: 0 }, Center { piece: 1, face: 0 },
                Center { piece: 2, face: 0 }, Center { piece: 3, face: 0 },
                // Cara D (Inferior)
                Center { piece: 4, face: 1 }, Center { piece: 5, face: 1 },
                Center { piece: 6, face: 1 }, Center { piece: 7, face: 1 },
                // Cara L (Izquierda)
                Center { piece: 8, face: 2 }, Center { piece: 9, face: 2 },
                Center { piece: 10, face: 2 }, Center { piece: 11, face: 2 },
                // Cara R (Derecha)
                Center { piece: 12, face: 3 }, Center { piece: 13, face: 3 },
                Center { piece: 14, face: 3 }, Center { piece: 15, face: 3 },
                // Cara F (Frontal)
                Center { piece: 16, face: 4 }, Center { piece: 17, face: 4 },
                Center { piece: 18, face: 4 }, Center { piece: 19, face: 4 },
                // Cara B (Trasera)
                Center { piece: 20, face: 5 }, Center { piece: 21, face: 5 },
                Center { piece: 22, face: 5 }, Center { piece: 23, face: 5 },
            ],
            edges: [
                // Aristas U (Superiores)
                Edge { piece: 0, orientation: 0 }, Edge { piece: 1, orientation: 0 },
                Edge { piece: 2, orientation: 0 }, Edge { piece: 3, orientation: 0 },
                // Aristas D (Inferiores)
                Edge { piece: 4, orientation: 0 }, Edge { piece: 5, orientation: 0 },
                Edge { piece: 6, orientation: 0 }, Edge { piece: 7, orientation: 0 },
                // Aristas laterales
                Edge { piece: 8, orientation: 0 }, Edge { piece: 9, orientation: 0 },
                Edge { piece: 10, orientation: 0 }, Edge { piece: 11, orientation: 0 },
                Edge { piece: 12, orientation: 0 }, Edge { piece: 13, orientation: 0 },
                Edge { piece: 14, orientation: 0 }, Edge { piece: 15, orientation: 0 },
                Edge { piece: 16, orientation: 0 }, Edge { piece: 17, orientation: 0 },
                Edge { piece: 18, orientation: 0 }, Edge { piece: 19, orientation: 0 },
                Edge { piece: 20, orientation: 0 }, Edge { piece: 21, orientation: 0 },
                Edge { piece: 22, orientation: 0 }, Edge { piece: 23, orientation: 0 },
            ],
            corners: [
                Corner { piece: 0, orientation: 0 }, // UFR
                Corner { piece: 1, orientation: 0 }, // UFL
                Corner { piece: 2, orientation: 0 }, // ULB
                Corner { piece: 3, orientation: 0 }, // UBR
                Corner { piece: 4, orientation: 0 }, // DFR
                Corner { piece: 5, orientation: 0 }, // DFL
                Corner { piece: 6, orientation: 0 }, // DLB
                Corner { piece: 7, orientation: 0 }, // DBR
            ],
        }
    }

    // Movimiento U (gira la cara superior 90 grados en sentido horario)
    pub fn move_u(&mut self) {
        // Permutar centros U
        let temp_centers = [self.centers[0], self.centers[1], self.centers[2], self.centers[3]];
        self.centers[0] = self.centers[3];  // UR -> UF
        self.centers[1] = temp_centers[0];  // UF -> UL
        self.centers[2] = temp_centers[1];  // UL -> UB
        self.centers[3] = temp_centers[2];  // UB -> UR
        
        // Permutar aristas U
        let temp_edges = [self.edges[0], self.edges[1], self.edges[2], self.edges[3]];
        self.edges[0] = self.edges[3];  // UR -> UF
        self.edges[1] = temp_edges[0];  // UF -> UL
        self.edges[2] = temp_edges[1];  // UL -> UB
        self.edges[3] = temp_edges[2];  // UB -> UR
        
        // Permutar esquinas U
        let temp_corners = [self.corners[0], self.corners[1], self.corners[2], self.corners[3]];
        self.corners[0] = self.corners[3];  // UFR -> UBR
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[2] = temp_corners[1];  // ULB -> UFL
        self.corners[3] = temp_corners[2];  // UBR -> ULB
    }

    // Movimiento R (gira la cara derecha 90 grados en sentido horario)
    pub fn move_r(&mut self) {
        // Permutar centros R
        let temp_centers = [self.centers[12], self.centers[13], self.centers[14], self.centers[15]];
        self.centers[12] = self.centers[15];  // RF -> RB
        self.centers[13] = temp_centers[0];   // RU -> RF
        self.centers[14] = temp_centers[1];   // RD -> RU
        self.centers[15] = temp_centers[2];   // RB -> RD
        
        // Permutar aristas R
        let temp_edges = [self.edges[12], self.edges[13], self.edges[14], self.edges[15]];
        self.edges[12] = self.edges[15];  // RF -> RB
        self.edges[13] = temp_edges[0];   // RU -> RF
        self.edges[14] = temp_edges[1];   // RD -> RU
        self.edges[15] = temp_edges[2];   // RB -> RD
        
        // Permutar esquinas R
        let temp_corners = [self.corners[0], self.corners[4], self.corners[7], self.corners[3]];
        self.corners[0] = self.corners[4];  // UFR -> DFR
        self.corners[4] = self.corners[7];  // DFR -> DBR
        self.corners[7] = self.corners[3];  // DBR -> UBR
        self.corners[3] = temp_corners[0];  // UBR -> UFR
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
        self.corners[7].orientation = (self.corners[7].orientation + 2) % 3;
        self.corners[3].orientation = (self.corners[3].orientation + 1) % 3;
    }

    // Movimiento F (gira la cara frontal 90 grados en sentido horario)
    pub fn move_f(&mut self) {
        // Permutar centros F
        let temp_centers = [self.centers[16], self.centers[17], self.centers[18], self.centers[19]];
        self.centers[16] = self.centers[19];  // FR -> FD
        self.centers[17] = temp_centers[0];   // FU -> FR
        self.centers[18] = temp_centers[1];   // FD -> FL
        self.centers[19] = temp_centers[2];   // FL -> FU
        
        // Permutar aristas F
        let temp_edges = [self.edges[16], self.edges[17], self.edges[18], self.edges[19]];
        self.edges[16] = self.edges[19];  // FR -> FD
        self.edges[17] = temp_edges[0];   // FU -> FR
        self.edges[18] = temp_edges[1];   // FD -> FL
        self.edges[19] = temp_edges[2];   // FL -> FU
        
        // Permutar esquinas F
        let temp_corners = [self.corners[0], self.corners[1], self.corners[5], self.corners[4]];
        self.corners[0] = self.corners[5];  // UFR -> DFL
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[5] = temp_corners[2];  // DFL -> DFR
        self.corners[4] = temp_corners[1];  // DFR -> UFL
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 1) % 3;
        self.corners[5].orientation = (self.corners[5].orientation + 2) % 3;
        self.corners[1].orientation = (self.corners[1].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
    }

    // Verifica si el cubo está resuelto
    pub fn is_solved(&self) -> bool {
        // Verificar centros
        for i in 0..24 {
            if self.centers[i].piece != i {
                return false;
            }
        }
        
        // Verificar aristas
        for i in 0..24 {
            if self.edges[i].piece != i || self.edges[i].orientation != 0 {
                return false;
            }
        }
        
        // Verificar esquinas
        for i in 0..8 {
            if self.corners[i].piece != i || self.corners[i].orientation != 0 {
                return false;
            }
        }
        
        true
    }

    // Calcula un hash del estado actual del cubo
    pub fn get_state_hash(&self) -> u64 {
        use std::collections::hash_map::DefaultHasher;
        use std::hash::{Hash, Hasher};
        
        let mut hasher = DefaultHasher::new();
        self.hash(&mut hasher);
        hasher.finish()
    }

    // Aplica una secuencia de movimientos
    pub fn apply_sequence(&mut self, sequence: &str) {
        for move_char in sequence.chars() {
            match move_char {
                'U' => self.move_u(),
                'R' => self.move_r(),
                'F' => self.move_f(),
                'D' => {
                    // Doble movimiento U: U U
                    self.move_u();
                    self.move_u();
                }
                'L' => {
                    // Doble movimiento R: R R
                    self.move_r();
                    self.move_r();
                }
                'B' => {
                    // Doble movimiento F: F F
                    self.move_f();
                    self.move_f();
                }
                ' ' | '\n' | '\t' => continue, // Ignorar espacios
                _ => {} // Otros caracteres se ignoran
            }
        }
    }
}

impl fmt::Display for Cube4x4x4 {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        writeln!(f, "Cube 4x4x4 State:")?;
        writeln!(f, "Centers:")?;
        for (i, center) in self.centers.iter().enumerate() {
            writeln!(f, "  Center {}: piece={}, face={}", i, center.piece, center.face)?;
        }
        writeln!(f, "Edges:")?;
        for (i, edge) in self.edges.iter().enumerate() {
            writeln!(f, "  Edge {}: piece={}, orientation={}", i, edge.piece, edge.orientation)?;
        }
        writeln!(f, "Corners:")?;
        for (i, corner) in self.corners.iter().enumerate() {
            writeln!(f, "  Corner {}: piece={}, orientation={}", i, corner.piece, corner.orientation)?;
        }
        Ok(())
    }
}

impl std::hash::Hash for Cube4x4x4 {
    fn hash<H: std::hash::Hasher>(&self, state: &mut H) {
        self.centers.hash(state);
        self.edges.hash(state);
        self.corners.hash(state);
    }
}

// Pseudocódigo para RubikPoW en el cubo 4×4×4
pub fn rubik_pow_challenge(target_difficulty: u64) -> Option<Vec<Move>> {
    let mut cube = Cube4x4x4::new();
    let mut moves = Vec::new();
    
    loop {
        // Generar un estado objetivo aleatorio
        let target_state = generate_random_state();
        
        // Intentar resolver el cubo desde el estado objetivo
        if let Some(solution) = solve_cube(&target_state) {
            // Verificar si la solución cumple con la dificultad objetivo
            if verify_solution(&solution, target_difficulty) {
                return Some(solution);
            }
        }
        
        // Si no se encuentra solución, generar un nuevo estado objetivo
        moves.clear();
    }
}

// Función de verificación (rápida)
pub fn verify_solution(moves: &[Move], target_difficulty: u64) -> bool {
    let mut cube = Cube4x4x4::new();
    
    // Aplicar los movimientos al cubo resuelto
    for &move_op in moves {
        match move_op {
            Move::U => cube.move_u(),
            Move::R => cube.move_r(),
            Move::F => cube.move_f(),
            // Otros movimientos...
        }
    }
    
    // Calcular hash del estado final
    let final_hash = cube.get_state_hash();
    
    // Verificar si el hash cumple con la dificultad objetivo
    final_hash < target_difficulty
}

## Aplicaciones en QubitCoin

### Seguridad Criptográfica

El cubo 4×4×4 proporciona:

- Espacio de estados: ≈ 7.4 × 10^45
- Grupo Simétrico S48: 48! ≈ 1.24 × 10^61
- Seguridad comparable a NIST PQC Security Level 5
- Resistencia a algoritmos cuánticos como Grover

### Asimetría Computacional

- Tiempo de resolución (minero): Exponencial en el tamaño del espacio de búsqueda
- Tiempo de verificación (nodo): Polinomial O(n) donde n es el número de movimientos
- Relación resolución/verificación: > 10^10:1
