# Documento Técnico del Cubo 7×7×7 - QubitCoin

## Descripción Matemática

El cubo 7×7×7 es el cubo más complejo de la familia de cubos de Rubik implementados en QubitCoin. Este cubo proporciona el nivel máximo de complejidad matemática disponible para aplicaciones que requieren seguridad absoluta.

### Grupo de Permutaciones

El estado del cubo 7×7×7 puede representarse como un elemento del grupo de permutaciones:

G = S147 × S144 × S8 ⋊ (Z2^144 × Z3^8)

Donde:
- S147: permutaciones de las 147 piezas centrales (49 centros por cara × 6 caras - 9 centros por vértice × 8 vértices / 4)
- S144: permutaciones de las 144 piezas de borde
- S8: permutaciones de las 8 esquinas
- Z2^144: orientaciones de las piezas de borde
- Z3^8: orientaciones de las esquinas

### Espacio de Estados

- Número total de estados posibles: ≈ 1.9 × 10^160
- Número de estados alcanzables mediante giros legales: ≈ 1.9 × 10^160
- Este número excede en órdenes de magnitud el número de átomos en el universo observable (≈ 10^80)

- **Tiempo de Verificación**: < 1.5 ms
- **Nivel de Seguridad**: Superior a NIST PQC Security Level 5 por varios órdenes de magnitud

## Código Rust para el Cubo 7×7×7

```rust
use std::fmt;

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Center {
    pub piece: u8,      // Identificador de la pieza central (0-146)
    pub face: u8,       // Cara a la que pertenece (0-5)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Edge {
    pub piece: u8,      // Identificador de la pieza de borde (0-143)
    pub orientation: u8, // Orientación (0, 1)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Corner {
    pub piece: u8,      // Identificador de la esquina (0-7)
    pub orientation: u8, // Orientación (0, 1, 2)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Cube7x7x7 {
    centers: [Center; 147],  // 49 centros por cara × 6 caras - 9 centros por vértice × 8 vértices / 4 = 147 centros
    edges: [Edge; 144],      // 24 aristas por cara × 6 caras - 4 aristas por vértice × 8 vértices / 2 = 144 aristas
    corners: [Corner; 8],    // 8 esquinas
}

impl Cube7x7x7 {
    pub fn new() -> Self {
        // Estado resuelto
        let mut centers = [Center { piece: 0, face: 0 }; 147];
        let mut edges = [Edge { piece: 0, orientation: 0 }; 144];
        let corners = [
            Corner { piece: 0, orientation: 0 }, // UFR
            Corner { piece: 1, orientation: 0 }, // UFL
            Corner { piece: 2, orientation: 0 }, // ULB
            Corner { piece: 3, orientation: 0 }, // UBR
            Corner { piece: 4, orientation: 0 }, // DFR
            Corner { piece: 5, orientation: 0 }, // DFL
            Corner { piece: 6, orientation: 0 }, // DLB
            Corner { piece: 7, orientation: 0 }, // DBR
        ];
        
        // Inicializar centros
        for i in 0..147 {
            centers[i] = Center { piece: i as u8, face: (i / 24) as u8 };
        }
        
        // Inicializar aristas
        for i in 0..144 {
            edges[i] = Edge { piece: i as u8, orientation: 0 };
        }
        
        Cube7x7x7 {
            centers,
            edges,
            corners,
        }
    }

    // Movimiento U (gira la cara superior 90 grados en sentido horario)
    pub fn move_u(&mut self) {
        // Permutar centros U (fila superior)
        let temp_centers_row1 = [
            self.centers[0], self.centers[1], self.centers[2], 
            self.centers[3], self.centers[4], self.centers[5], 
            self.centers[6]
        ];
        self.centers[0] = self.centers[6];  // UR -> UF
        self.centers[1] = temp_centers_row1[0];  // UF -> UL
        self.centers[2] = temp_centers_row1[1];  // UL -> UB
        self.centers[3] = temp_centers_row1[2];  // UB -> UBL
        self.centers[4] = temp_centers_row1[3];  // UBL -> UBR
        self.centers[5] = temp_centers_row1[4];  // UBR -> URF
        self.centers[6] = temp_centers_row1[5];  // URF -> UR
        
        // Permutar aristas U
        let temp_edges = [self.edges[0], self.edges[1], self.edges[2], self.edges[3]];
        self.edges[0] = self.edges[3];  // UR -> UF
        self.edges[1] = temp_edges[0];  // UF -> UL
        self.edges[2] = temp_edges[1];  // UL -> UB
        self.edges[3] = temp_edges[2];  // UB -> UR
        
        // Permutar esquinas U
        let temp_corners = [self.corners[0], self.corners[1], self.corners[2], self.corners[3]];
        self.corners[0] = self.corners[3];  // UFR -> UBR
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[2] = temp_corners[1];  // ULB -> UFL
        self.corners[3] = temp_corners[2];  // UBR -> ULB
    }

    // Movimiento R (gira la cara derecha 90 grados en sentido horario)
    pub fn move_r(&mut self) {
        // Permutar centros R
        let temp_centers_row1 = [
            self.centers[24], self.centers[25], self.centers[26], 
            self.centers[27], self.centers[28], self.centers[29], 
            self.centers[30]
        ];
        self.centers[24] = self.centers[30];  // RF -> RB
        self.centers[25] = temp_centers_row1[0];  // RU -> RF
        self.centers[26] = temp_centers_row1[1];  // RM -> RU
        self.centers[27] = temp_centers_row1[2];  // RM -> RM
        self.centers[28] = temp_centers_row1[3];  // RM -> RM
        self.centers[29] = temp_centers_row1[4];  // RD -> RM
        self.centers[30] = temp_centers_row1[5];  // RB -> RD
        
        // Permutar aristas R
        let temp_edges = [self.edges[24], self.edges[25], self.edges[26], self.edges[27]];
        self.edges[24] = self.edges[27];  // RF -> RB
        self.edges[25] = temp_edges[0];   // RU -> RF
        self.edges[26] = temp_edges[1];   // RD -> RU
        self.edges[27] = temp_edges[2];   // RB -> RD
        
        // Permutar esquinas R
        let temp_corners = [self.corners[0], self.corners[4], self.corners[7], self.corners[3]];
        self.corners[0] = self.corners[4];  // UFR -> DFR
        self.corners[4] = self.corners[7];  // DFR -> DBR
        self.corners[7] = self.corners[3];  // DBR -> UBR
        self.corners[3] = temp_corners[0];  // UBR -> UFR
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
        self.corners[7].orientation = (self.corners[7].orientation + 2) % 3;
        self.corners[3].orientation = (self.corners[3].orientation + 1) % 3;
    }

    // Movimiento F (gira la cara frontal 90 grados en sentido horario)
    pub fn move_f(&mut self) {
        // Permutar centros F
        let temp_centers_row1 = [
            self.centers[48], self.centers[49], self.centers[50], 
            self.centers[51], self.centers[52], self.centers[53], 
            self.centers[54]
        ];
        self.centers[48] = self.centers[54];  // FR -> FD
        self.centers[49] = temp_centers_row1[0];  // FU -> FR
        self.centers[50] = temp_centers_row1[1];  // FM -> FU
        self.centers[51] = temp_centers_row1[2];  // FM -> FM
        self.centers[52] = temp_centers_row1[3];  // FM -> FM
        self.centers[53] = temp_centers_row1[4];  // FM -> FD
        self.centers[54] = temp_centers_row1[5];  // FD -> FL
        
        // Permutar aristas F
        let temp_edges = [self.edges[48], self.edges[49], self.edges[50], self.edges[51]];
        self.edges[48] = self.edges[51];  // FR -> FD
        self.edges[49] = temp_edges[0];   // FU -> FR
        self.edges[50] = temp_edges[1];   // FD -> FL
        self.edges[51] = temp_edges[2];   // FL -> FU
        
        // Permutar esquinas F
        let temp_corners = [self.corners[0], self.corners[1], self.corners[5], self.corners[4]];
        self.corners[0] = self.corners[5];  // UFR -> DFL
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[5] = temp_corners[2];  // DFL -> DFR
        self.corners[4] = temp_corners[1];  // DFR -> UFL
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 1) % 3;
        self.corners[5].orientation = (self.corners[5].orientation + 2) % 3;
        self.corners[1].orientation = (self.corners[1].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
    }

    // Verifica si el cubo está resuelto
    pub fn is_solved(&self) -> bool {
        // Verificar centros
        for i in 0..147 {
            if self.centers[i].piece != i as u8 {
                return false;
            }
        }
        
        // Verificar aristas
        for i in 0..144 {
            if self.edges[i].piece != i as u8 || self.edges[i].orientation != 0 {
                return false;
            }
        }
        
        // Verificar esquinas
        for i in 0..8 {
            if self.corners[i].piece != i as u8 || self.corners[i].orientation != 0 {
                return false;
            }
        }
        
        true
    }

    // Calcula un hash del estado actual del cubo
    pub fn get_state_hash(&self) -> u64 {
        use std::collections::hash_map::DefaultHasher;
        use std::hash::{Hash, Hasher};
        
        let mut hasher = DefaultHasher::new();
        self.hash(&mut hasher);
        hasher.finish()
    }

    // Aplica una secuencia de movimientos
    pub fn apply_sequence(&mut self, sequence: &str) {
        for move_char in sequence.chars() {
            match move_char {
                'U' => self.move_u(),
                'R' => self.move_r(),
                'F' => self.move_f(),
                'D' => {
                    // Doble movimiento U: U U
                    self.move_u();
                    self.move_u();
                }
                'L' => {
                    // Doble movimiento R: R R
                    self.move_r();
                    self.move_r();
                }
                'B' => {
                    // Doble movimiento F: F F
                    self.move_f();
                    self.move_f();
                }
                ' ' | '\n' | '\t' => continue, // Ignorar espacios
                _ => {} // Otros caracteres se ignoran
            }
        }
    }
}

impl fmt::Display for Cube7x7x7 {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        writeln!(f, "Cube 7x7x7 State:")?;
        writeln!(f, "Centers (first 10):")?;
        for i in 0..std::cmp::min(10, self.centers.len()) {
            writeln!(f, "  Center {}: piece={}, face={}", i, self.centers[i].piece, self.centers[i].face)?;
        }
        writeln!(f, "Edges (first 10):")?;
        for i in 0..std::cmp::min(10, self.edges.len()) {
            writeln!(f, "  Edge {}: piece={}, orientation={}", i, self.edges[i].piece, self.edges[i].orientation)?;
        }
        writeln!(f, "Corners:")?;
        for (i, corner) in self.corners.iter().enumerate() {
            writeln!(f, "  Corner {}: piece={}, orientation={}", i, corner.piece, corner.orientation)?;
        }
        Ok(())
    }
}

impl std::hash::Hash for Cube7x7x7 {
    fn hash<H: std::hash::Hasher>(&self, state: &mut H) {
        self.centers.hash(state);
        self.edges.hash(state);
        self.corners.hash(state);
    }
}

        assert_eq!(cube.corners[3].piece, 2); // Antes era 3 (UBR -> ULB)
    }
}
```

## Conclusiones

El cubo 7×7×7 representa el pináculo de la seguridad criptográfica basada en teoría de grupos implementada en QubitCoin. Con un espacio de estados que excede en órdenes de magnitud el número de átomos en el universo observable, proporciona una base matemática prácticamente invulnerable a cualquier ataque conocido, incluidos los teóricos cuánticos.

Aunque más exigente en recursos computacionales, el cubo 7×7×7 ofrece capacidades únicas para aplicaciones que requieren la seguridad más extrema disponible en la tecnología actual.
