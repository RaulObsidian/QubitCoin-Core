# Documento Técnico del Cubo 5×5×5 - QubitCoin

## Descripción Matemática

El cubo 5×5×5, también conocido como Profesor Cube, es una extensión más compleja de la familia de cubos de Rubik. Aunque no es el cubo principal en QubitCoin, proporciona un nivel adicional de complejidad matemática para aplicaciones específicas.

### Grupo de Permutaciones

El estado del cubo 5×5×5 puede representarse como un elemento del grupo de permutaciones:

G = S50 × S48 × S8 ⋊ (Z2^48 × Z3^8)

Donde:
- S50: permutaciones de las 50 piezas centrales (25 centros por cara × 6 caras - 4 centros por vértice × 8 vértices / 4)
- S48: permutaciones de las 48 piezas de borde
- S8: permutaciones de las 8 esquinas
- Z2^48: orientaciones de las piezas de borde
- Z3^8: orientaciones de las esquinas

### Espacio de Estados

- Número total de estados posibles: ≈ 2.8 × 10^74
- Número de estados alcanzables mediante giros legales: ≈ 2.8 × 10^74
- Este número es significativamente mayor que el del cubo 4×4×4

use std::fmt;

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Center {
    pub piece: u8,      // Identificador de la pieza central (0-49)
    pub face: u8,       // Cara a la que pertenece (0-5)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Edge {
    pub piece: u8,      // Identificador de la pieza de borde (0-47)
    pub orientation: u8, // Orientación (0, 1)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Corner {
    pub piece: u8,      // Identificador de la esquina (0-7)

    // Movimiento U (gira la cara superior 90 grados en sentido horario)
    pub fn move_u(&mut self) {
        // Permutar centros U (fila superior)
        let temp_centers_row1 = [self.centers[0], self.centers[1], self.centers[2], self.centers[3], self.centers[4]];
        self.centers[0] = self.centers[4];  // UR -> UF
        self.centers[1] = temp_centers_row1[0];  // UF -> UL
        self.centers[2] = temp_centers_row1[1];  // UL -> UB
        self.centers[3] = temp_centers_row1[2];  // UB -> UR
        // Centro central no cambia: self.centers[12]
        
        // Permutar centros U (fila inferior)
        let temp_centers_row2 = [self.centers[20], self.centers[21], self.centers[22], self.centers[23], self.centers[24]];
        self.centers[20] = self.centers[24];  // UR -> UF
        self.centers[21] = temp_centers_row2[0];  // UF -> UL
        self.centers[22] = temp_centers_row2[1];  // UL -> UB
        self.centers[23] = temp_centers_row2[2];  // UB -> UR
        // Centro central no cambia: self.centers[12]
        
        // Permutar aristas U
        let temp_edges = [self.edges[0], self.edges[1], self.edges[2], self.edges[3]];
        self.edges[0] = self.edges[3];  // UR -> UF
        self.edges[1] = temp_edges[0];  // UF -> UL
        self.edges[2] = temp_edges[1];  // UL -> UB
        self.edges[3] = temp_edges[2];  // UB -> UR
        
        // Permutar esquinas U
        let temp_corners = [self.corners[0], self.corners[1], self.corners[2], self.corners[3]];
        self.corners[0] = self.corners[3];  // UFR -> UBR
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[2] = temp_corners[1];  // ULB -> UFL
        self.corners[3] = temp_corners[2];  // UBR -> ULB
    }

    // Movimiento R (gira la cara derecha 90 grados en sentido horario)
    pub fn move_r(&mut self) {
        // Permutar centros R
        // Similar a U pero en la cara derecha
        
        // Permutar aristas R
        let temp_edges = [self.edges[32], self.edges[33], self.edges[34], self.edges[35]];
        self.edges[32] = self.edges[35];  // RF -> RB
        self.edges[33] = temp_edges[0];   // RU -> RF
        self.edges[34] = temp_edges[1];   // RD -> RU
        self.edges[35] = temp_edges[2];   // RB -> RD
        
        // Permutar esquinas R
        let temp_corners = [self.corners[0], self.corners[4], self.corners[7], self.corners[3]];
        self.corners[0] = self.corners[4];  // UFR -> DFR
        self.corners[4] = self.corners[7];  // DFR -> DBR
        self.corners[7] = self.corners[3];  // DBR -> UBR
        self.corners[3] = temp_corners[0];  // UBR -> UFR
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
        self.corners[7].orientation = (self.corners[7].orientation + 2) % 3;
        self.corners[3].orientation = (self.corners[3].orientation + 1) % 3;
    }

    // Movimiento F (gira la cara frontal 90 grados en sentido horario)
    pub fn move_f(&mut self) {
        // Permutar centros F
        // Similar a U pero en la cara frontal
        
        // Permutar aristas F
        let temp_edges = [self.edges[16], self.edges[17], self.edges[18], self.edges[19]];
        self.edges[16] = self.edges[19];  // FR -> FD
        self.edges[17] = temp_edges[0];   // FU -> FR
        self.edges[18] = temp_edges[1];   // FD -> FL
        self.edges[19] = temp_edges[2];   // FL -> FU
        
        // Permutar esquinas F
        let temp_corners = [self.corners[0], self.corners[1], self.corners[5], self.corners[4]];
        self.corners[0] = self.corners[5];  // UFR -> DFL
        self.corners[1] = temp_corners[0];  // UFL -> UFR
        self.corners[5] = temp_corners[2];  // DFL -> DFR
        self.corners[4] = temp_corners[1];  // DFR -> UFL
        
        // Ajustar orientaciones de esquinas
        self.corners[0].orientation = (self.corners[0].orientation + 1) % 3;
        self.corners[5].orientation = (self.corners[5].orientation + 2) % 3;
        self.corners[1].orientation = (self.corners[1].orientation + 2) % 3;
        self.corners[4].orientation = (self.corners[4].orientation + 1) % 3;
    }

    // Verifica si el cubo está resuelto
    pub fn is_solved(&self) -> bool {
        // Verificar centros
        for i in 0..50 {
            if self.centers[i].piece != i {
                return false;
            }
        }
        
        // Verificar aristas
        for i in 0..48 {
            if self.edges[i].piece != i || self.edges[i].orientation != 0 {
                return false;
            }
        }
        
        // Verificar esquinas
        for i in 0..8 {
            if self.corners[i].piece != i || self.corners[i].orientation != 0 {
                return false;
            }
        }
        
        true
    }

    // Calcula un hash del estado actual del cubo
    pub fn get_state_hash(&self) -> u64 {
        use std::collections::hash_map::DefaultHasher;
        use std::hash::{Hash, Hasher};
        
        let mut hasher = DefaultHasher::new();
        self.hash(&mut hasher);
        hasher.finish()
    }

    // Aplica una secuencia de movimientos
    pub fn apply_sequence(&mut self, sequence: &str) {
        for move_char in sequence.chars() {
            match move_char {
                'U' => self.move_u(),
                'R' => self.move_r(),
                'F' => self.move_f(),
                'D' => {
                    // Doble movimiento U: U U
                    self.move_u();
                    self.move_u();
                }
                'L' => {
                    // Doble movimiento R: R R
                    self.move_r();
                    self.move_r();
                }
                'B' => {
                    // Doble movimiento F: F F
                    self.move_f();
                    self.move_f();
                }
                ' ' | '\n' | '\t' => continue, // Ignorar espacios
                _ => {} // Otros caracteres se ignoran
            }
        }
    }
}

            writeln!(f, "  Edge {}: piece={}, orientation={}", i, self.edges[i].piece, self.edges[i].orientation)?;
        }
        writeln!(f, "Corners:")?;
        for (i, corner) in self.corners.iter().enumerate() {
            writeln!(f, "  Corner {}: piece={}, orientation={}", i, corner.piece, corner.orientation)?;
        }
        Ok(())
    }
}

impl std::hash::Hash for Cube5x5x5 {
    fn hash<H: std::hash::Hasher>(&self, state: &mut H) {
        self.centers.hash(state);
        self.edges.hash(state);
        self.corners.hash(state);
    }
}

## Aplicaciones en QubitCoin

### Uso en RubikPoW

El cubo 5×5×5 puede utilizarse para:

- Niveles de seguridad extremadamente altos
- Aplicaciones que requieren máxima resistencia cuántica
- Validación de transacciones de alto valor

### Seguridad

- Espacio de estados: ≈ 2.8 × 10^74
- Mayor seguridad que el cubo 4×4×4
- Adecuado para protección contra ataques futuros

## Comparación con Otros Cubos

| Cubo | Espacio de Estados | Seguridad Relativa | Uso Principal |
|------|-------------------|-------------------|---------------|
| 2×2×2 | ~3.6 × 10^6 | Baja | Pruebas, nodos ligeros |
| 3×3×3 | ~4.3 × 10^19 | Media | Transacciones de valor medio |
| 4×4×4 | ~7.4 × 10^45 | Alta | Principal en QubitCoin |
| 5×5×5 | ~2.8 × 10^74 | Extrema | Altas transacciones, seguridad máxima |

## Conclusiones

El cubo 5×5×5 proporciona un nivel adicional de complejidad matemática para aplicaciones que requieren seguridad extrema. Aunque no es el cubo principal en QubitCoin, ofrece capacidades valiosas para ciertos casos de uso especializados.
